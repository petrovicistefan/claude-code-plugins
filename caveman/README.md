# Caveman Mode: Short Answers

Make Claude answer short and to the point: the answer or the code first, no filler.

## What it does

When caveman mode is on, Claude keeps answers to a few bullets or sentences, shows code only when you need it and asks one short question instead of guessing. Technical details such as names, error messages and commands stay exact, and warnings before destructive actions are kept. Shorter answers also mean fewer output tokens.

## Use it

- `/caveman:caveman` to switch it on
- Say "normal answers" to switch it off
- Or simply ask: "Caveman mode, why does this test fail?"

## Data

The plugin only contains instructions for Claude. It runs no code and sends no data anywhere.

## Not related to other projects

This plugin is a short set of instructions written for this repository. It is not related to the `caveman` project by JuliusBrussee.
