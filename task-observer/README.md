# Task Observer: Learn Your Preferences

Turn your corrections into lasting rules, so Claude Code follows your conventions in every session.

## What it does

When you correct how Claude works or state a lasting preference, such as your package manager, testing layout, comment style or answer language, Claude writes it as one short rule and asks where to save it: `CLAUDE.md`, which is shared with your team through git, or `CLAUDE.local.md`, which is only for you. Claude Code loads these files at the start of every session. Claude replaces outdated rules instead of adding contradictions, and can show and tidy the list on request.

## Use it

- `/task-observer:learn always use pnpm`
- `/task-observer:preferences`

## Data

Rules are saved in files in your project, only after you agree. Nothing is sent anywhere.

## Not related to other projects

This plugin only writes your preferences to `CLAUDE.md`. It is not related to the `task-observer` skill in `rebelytics/one-skill-to-rule-them-all`.
